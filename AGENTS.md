# AGENTS.md

> Baseline guidance for AI agents working in document repositories.

New project from this template? Follow `docs/use-this-template.md` first. It covers customizing scopes, conventions, and removing template placeholders.

## Document conventions

- Use Markdown unless the repo owner specifies otherwise.
- One topic per file. Use `kebab-case.md` filenames.
- Put documents in `content/` unless the project uses a different layout.

## Workflow

Read `DEVELOPING.md` before committing. Commit only after hooks pass.
